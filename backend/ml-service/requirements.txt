# Offload ML Service — runtime dependencies
#
# This service is a FastAPI app that calls the OpenAI/Anthropic HTTP APIs to
# parse transcripts into atomic objects. It runs no models locally.
#
# It used to declare the whole local-inference stack — torch, torchaudio,
# transformers, sentence-transformers, spacy, scikit-learn, librosa, numpy —
# left over from when local Whisper and local embeddings were the plan.
# Transcription moved to Deepgram + OpenAI and embeddings are generated in the
# Node API, but the requirements were never pruned. Nothing imported any of it,
# and it cost a 6.3GB image and ~20-minute deploys.
#
# Keep this list to what is actually imported. Dev/test tools live in
# requirements-dev.txt so they stay out of the production image.

# Web framework
fastapi==0.109.0
uvicorn[standard]==0.27.0
pydantic==2.5.3

# HTTP client for the LLM provider APIs.
#
# Upper bound is load-bearing: httpx 0.28 removed the `app=` shortcut that
# starlette 0.35's TestClient still uses, and fastapi 0.109 pins
# starlette<0.36. This ceiling used to come in transitively from the (now
# removed) heavy packages; without it stated here, httpx floats to 0.28 and
# every test in test_main.py fails at collection. Raise it together with
# fastapi/starlette, not on its own.
httpx>=0.26.0,<0.28

# Config
python-dotenv>=1.0.0
